# Kraft

Meine Krafttrainings-App als PWA: Trainingsplan A/B/C, Trainingsmodus mit Pausentimer und Progressionsvorschlägen, Verlauf, Körpergewicht, Backup. Alles lokal auf dem Handy, auf Deutsch.

Anleitung zum Installieren: [ANLEITUNG.md](ANLEITUNG.md)

- `npm run dev` startet die App lokal
- `npm test` führt die automatischen Tests aus
- `npm run build` baut die fertige Version in `dist/`
